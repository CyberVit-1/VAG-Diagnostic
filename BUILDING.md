# Сборка и физический тест 0.1.0

## Условия
- Android Studio с установленным Android SDK Platform 35 и Build Tools.
- Gradle 8.11.1 и JDK 17+ (совместимую конфигурацию выбирает Android Studio).
- Проект содержит Gradle Kotlin DSL, **но не содержит gradle-wrapper.jar**: в изолированной среде невозможно было скачать Gradle/Android SDK. В Android Studio создайте wrapper средствами установленной Gradle: `gradle wrapper --gradle-version 8.11.1`, затем `./gradlew :app:assembleDebug`. Можно запустить `:app:assembleDebug` через Gradle tool window при настроенной локальной Gradle.
- APK при успешной сборке появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка парсера без Android SDK
При установленном `kotlinc`:
```
kotlinc app/src/main/java/com/vagdiagnostic/app/core/DiagnosticCore.kt tools/DiagnosticCoreSmoke.kt -include-runtime -d /tmp/vag-core-smoke.jar
java -jar /tmp/vag-core-smoke.jar
```

## Первый реальный сеанс — Wi-Fi ELM327
1. Автомобиль неподвижен; зажигание в положении, допускающем диагностику. Не применять к автомобилю с критически опасными симптомами, требующими сервиса.
2. Подключить ELM327 к штатному диагностическому разъёму, телефон — к Wi-Fi сети адаптера.
3. В экране «Подключение» указать **фактические** IP и порт из паспорта адаптера (показанные значения — лишь настройки по умолчанию, не результаты обнаружения).
4. Нажать «Подключиться к адаптеру» и убедиться, что состояния «Адаптер» и «Автомобиль» разделены. При `NO DATA` не считать сканирование успешным.
5. Если OBD-II связь подтверждена, запустить «Диагностика»; в первой версии опрашиваются только 03/07/0A.
6. Сохранить «Настройки → Экспортировать журнал TXT» через системный документ-пикер. Экспорт маскирует потенциальный VIN; перед передачей проверить содержимое вручную.
7. Если замечены странные данные, не запускать сканирование повторно без разбора RAW протокола.

## Какие данные нужны для следующей разработки
- Модель и год автомобиля, тип двигателя (без VIN).
- Название/тип ELM327 и его IP/порт или Bluetooth профиль.
- Export журнала по успешному подключению и после одного сканирования.
- Скриншот состояния связи и карточек при ошибке (если есть).

## Нельзя принимать за успешное испытание
- Пройденные тесты JVM, ответы симулятора или загруженный Android UI.
- Успешное подключение TCP при отсутствии ответа на `0100`.
- Пустой ответ на `03/07/0A` как доказательство нулевых DTC.
