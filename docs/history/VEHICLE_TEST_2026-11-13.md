## Корректное значение46 и оставшаяся неизвестность04

[Ross-Tech](https://www.ross-tech.com/vag-com/vw_issues.php) объясняет:
у части2009+ платформ46 остаётся виртуальной записью Gateway, функции
объединены с09. Для
[BCM PQ35](https://wiki.ross-tech.com/wiki/index.php/VW_Golf_(5K)_Body_Control_Module)
область применения определяется в том числе Component. В журнале подтверждён
только номер09, тип компонента отсутствует: автоматическая классификация
46 как виртуального без него не обоснована. Существующее строгое правило
связи функций требует свежего полного чтения09 и подтверждённого BCM PQ35.

Для04 перенос функций G85 между ECU зависит от поколения. Инструкции
настройки G85 через44 не доказывают отсутствие самостоятельной DTC-памяти04.
Отдельный04 по-прежнему не подтверждён. Данные03/44/09 не копируются в04/46.

0.3.17 сокращает только законченные тихие preflight для адресов, уже
подтверждённых installation list: один3E, один1003, затем собственный DTC,

Тайминги DTC/ISO-TP и предел собственных повторов не сокращены.

Один недостающий Component09 читается после сохранения его DTC, только при
заявленном46 и известном семействе номера BCM. Полная инвентаризация не
включается. При неизвестном/отклонённом типе46 остаётся без подтверждения;
при установленной связи функции не становятся отдельной прочитанной памятью.

Явно включённый режим полной дополнительной идентификации сохраняет прежний
preflight; оптимизация относится к обычному минимальному чтению приложения.
