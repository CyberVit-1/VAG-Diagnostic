# Логический адрес и диагностический блок — правила PQ35

Исследование02.11.2026 после сравнения результатов. Радио исключено из этой
задачи. Прямое подключение04/46 в TXT0.3.9 не получило ответа ни по TP2.0,
ни по известному физическому UDS. Повторного подбора CAN ID не добавляется.

## 46 и BCM PQ35

Фактический09 идентифицирован как1K0937086H, componentBCM PQ35 M, его память
DTC прочитана. Ross-Tech указывает для BCM PQ35, что функции прежнего46
перенесены в09 и отдельный адрес комфорта отсутствует:
[Body Control Module PQ35](https://wiki.ross-tech.com/wiki/index.php/VW_Golf_%285K%29_Body_Control_Module).
Это объяснение архитектуры, а не отказ чтения самостоятельного46 на этой
конфигурации. Правило нельзя распространять на любойBCM: например,
[Passat CC с3AABCM сохраняет отдельный46](https://wiki.ross-tech.com/wiki/index.php/VW_Passat_CC_%2835%29).

Автоматическая ссылка46→09 разрешается только для объявленного Gateway
адреса без собственного ответа, свежего полного чтения09, проверенного
номера семейства1K0/5K093708x и componentBCM PQ35. Ответивший46 всегда имеет
приоритет. Неизвестные/другие семейства не классифицируются по аналогии.

## 04 и G85 при MK70

Фактические идентификаторы:03 —1K0907379AK/MK70 M MASR,
44 —1K0909144R/EPS_ZFLS Kl.235. Для MK70 документация направляет работу сG85
в44: [MK70/G85](https://wiki.ross-tech.com/wiki/index.php/VW_Golf_%281K%29_Brake_Electronics_%28MK70%29).
Это подтверждает диагностический путь функции через44; само по себе не
доказывает отсутствие отдельного04 или отдельное чтение его DTC. В04 нельзя
копировать все ошибки44/03 или выдавать нулевой счётчик за полученный ответ.

Ссылка04→44 показывается только при совпадении семейства03/MK70 и44/EPS_ZFLS,
полном свежем чтении обоих контроллеров и отсутствии собственного ответа04.
ДляMK60/MK60EC1, других номеров, неполных родителей и ответившего04 правило
не применяется. Возможность другого физического размещения G85 не угадывается.

## Представление в приложении

VagDiagnosticTopology добавляет diagnosticHost/hostReason после фактического
опроса, без новых команд. Исходные state/source/DTC/answeredModes адреса
сохраняются: NO_RESPONSE не становится COMPLETE, чужие DTC не копируются,
число полных чтений не увеличивается. Карточка показывает связанный блок
и явно неподтверждённую собственную память. Это уточнение покрытия и причины
молчания логического адреса, не имитация ещё одного прочитанногоECU.

Поля истории JSON необязательные, Roomv1 не изменён. Старые записи получают
null; обратная совместимость и round trip проверены на Android.
Новые правила покрыты7отдельными проверками и интеграционным сценарием
опроса с молчащими04/46 и отвечающими родителями. Физического результата
новой версии и её скорости пока нет.
