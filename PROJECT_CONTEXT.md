# Состояние проекта — 14.11.2026

## Цель и действующие правила

Универсальная Android-диагностика VAG: автоматически находить установленные
блоки, показывать адрес, название и назначение, читать собственную память DTC
либо подтверждать отсутствие ошибок полным корректным ответом ECU.
Число блоков заранее не задано. Разработка не ограничена одним автомобилем.

Обязательны [AGENTS.md](AGENTS.md), полный [мастер-промпт](MASTER_PROMPT.md)
и [проектный процесс](.agents/skills/vag-diagnostic/SKILL.md).
Работа только на чтение: без стирания, кодирования, адаптаций, Security Access,
SFD и изменения диагностических фильтров. NO DATA и тайм-аут не означают
«ошибок нет». Программные проверки не заменяют автомобильное испытание.
При команде продолжать — автономно до проверенного APK для следующего
необходимого испытания, объединяя исправления в один кандидат.

## Архитектура и сохранность

core — разбор и модели; transport — последовательные транзакции ELM,
TP2.0/ISO-TP/UDS и независимые каналы; ViewModel/UI — представление;
Room/DataStore — история и настройки. UI не отправляет команды ECU.
Диагностика работает без интернета; Wi-Fi сокет использует нужную Android
Network, без привязки всего процесса. VIN виден локально, скрывается в экспорте
и не публикуется. Сохраняются RAW, частичные результаты и причины отказов.
Основной DTC читается до необязательных сведений, которые не должны блокировать
очередь. Кандидат профиля не считается найденным ECU без подтверждения.

Пользователь применяет чистую установку после отправки TXT; не повторять
советы об установке поверх и стандартные предупреждения без нового риска.
Не проверять подписи на текущем этапе. Исходные журналы и test fixtures сохранять.
