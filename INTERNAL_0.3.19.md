# Внутренний срез 0.3.19/code35 — 14.11.2026

Не является выдачей новой версии для автомобильного теста.

## Изменения

- Завершённое молчание фиксированной проверки SAE-формата при подтверждённом
  живом TP-канале выбирает основной OEM DTC-запрос в том же канале.
  Раньше перед ним без необходимости открывался новый канал. Частичный ответ,
  незавершённый pending, повреждение, IO и отмена этой ветвью не перехватываются.
- Однобайтовый ACK чужой последовательности не подтверждает запрос, но больше
  не уничтожает правильный ACK и DTC, уже стоящие за ним в очереди. Число кадров
  ограничено; malformed ACK остаётся ошибкой. Повтор DTC этим не добавляется.
- Уточнена формулировка связи G85: справочник MK70 описывает базовую установку
  через 44. Он не доказывает отсутствие отдельной памяти ошибок адреса 04.

До исправлений новые сценарии лишнего открытия канала и устаревшего ACK
воспроизводили отказ. После исправлений профильный прогон прошёл.
Полные локальные JVM и Android проверки протокольных изменений: по 545 тестов,
59 наборов, failures/errors/skips=0. DEX:870 методов, max112 registers,
max11924 code units, oversized=[]. Версия и формулировка уточнены после этих
прогонов; окончательное дерево52eb5e9 проверено CI отдельно.
[CI43591517595](https://github.com/CyberVit-1/VAG-Diagnostic/actions/runs/43591517595):
545/59 PASS, failures/errors/skips=0; сборка и DEX PASS.

того же дерева:241 ART-проверка, failures/ignored=0, без установки и машины.
