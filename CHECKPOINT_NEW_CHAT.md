## Текущий кандидат — 0.3.11 / code 27, 03.11.2026

Последняя опубликованная версия — 0.3.10/code26. Новый кандидат пока не выдан.
Локально: 380 JVM + 380 Android unit-тестов и assembleDebug прошли;
после уточнения распознавания VT-баннера повторно прошли 8 профильных тестов.
DEX: 724 метода, максимум 112 регистров / 8396 code units, превышений нет.
Проверка GitHub CI и запуск выбранных тестов с его APK на ART телефона ожидаются.
Ранее 138 ART-проверок прошли на промежуточном срезе; это не доказательство
для окончательного APK. Автомобильного испытания 0.3.11 ещё не было.

В согласованном read-only VAG CAN пути реализованы обнаружение Gateway,
известные TP2.0/UDS маршруты, подключения и чтение DTC, ограниченные повторы,
восстановление после протокольных ошибок, ручная ISO-TP сегментация обычных
адаптеров и подтверждаемые командами native STN/VT ветви. Ошибки Gateway
читаются до необязательной идентификации09; далее DTC читаются при обработке
каждого ECU. Повторная настройка адаптера сокращена кэшем только реально
подтверждённых настроек; запросы к ECU не кэшируются.

См. CONNECTION_PORT_AUDIT_2026-11-03.md: функциональная карта и границы.
Это перенос исследованных алгоритмов с адаптацией Android IO, а не буквальное
копирование исходного проекта или гарантия чтения каждого автомобиля.
Стирание, авторизация, изменение фильтра ECU, кодирование и другие записи
запрещены. VIN остаётся локальным; экспорт и GitHub должны быть обезличены.
Следующий шаг: CI → проверка фактического APK на ART без установки → единый
автомобильный тест. До прохождения этих проверок APK пользователю не выдавать.
