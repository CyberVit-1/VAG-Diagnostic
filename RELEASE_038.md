# 0.3.8 / 24 — консолидированный кандидат чтения

Статус подготовки: финальная программная проверка и GitHub CI. Физического
результата этой версии нет. Полное чтение всех установленных ECU не объявлено
подтверждённым.

Основные изменения относительно последнего автомобильного испытания 0.3.6:

- Продолжение очереди после строго распознанного чистого закрытия TP2.0:
  восстановление транспорта до нового ECU, ограниченный повтор молчавшего
  блока. Повреждённый или незавершённый обмен не переиспользуется.
- Раздельная обработка штатного закрытия после полного ответа: прочитанный
  DTC сохраняется; служебные данные кэшируются до открытия нового канала.
- Полный фиксированный каталог кандидатов, карты Gateway, функциональные
  ответы с проверкой владельца, независимая проверка 09 и процедура 61.
  Подтверждённый поддерживаемый номер Gateway разрешает поиск без VIN.
- Выбор CAN/UDS и адресации по конкретному ECU, точный физический flow control
  11/29 бит, ограниченный приём поздних FF/CF и ResponsePending.
- Идентификация и capabilities определяют формат DTC; основной результат
  сохраняется до дополнительных запросов. KWP и UDS extended records имеют
  проверку структуры и ASAM; неизвестные значения остаются исходными.
- Ошибка структуры необязательной записи не останавливает последующие ECU.
  Чужой SID/DTC, повреждённые кадры, IO и отмена не маскируются.
- Сохранены сворачиваемая сводка, отдельные кандидаты, локальный VIN и
  маскирование VIN при экспорте. Нет миграции или сброса Room v1.

Точная карта реализации и ограничений: [READ_ONLY_COVERAGE.md](READ_ONLY_COVERAGE.md).
Режим сейчас только чтение: без стирания ошибок, кодирования, исполнительных
тестов, SFD unlock и записи для отключения диагностического фильтра.
Защищённые ECU могут остаться недоступными. K-line/KWP1281, DoIP, CAN FD и
BLE-профили помимо NUS этим кандидатом не поддерживаются.

Последний физический журнал 0.3.6: 18 ID / 11 полных чтений. Предыдущий
результат 0.3.4: 15 полных чтений. Это исторические данные; 04/46 пока без
подтверждённого ответа, виртуальность не доказана. Численного предела поиска
или цели «19 блоков» нет.

## Сохранность данных перед установкой

Постоянный package com.vagdiagnostic.app. Подпись выдаваемого APK нужно
сопоставить с прежним APK до инструкции установки. Разная подпись препятствует
обновлению поверх старой версии. Удаление приложения уничтожает его Room-историю,
внутренние RAW-журналы и настройки. Сначала сохранить и проверить внешние TXT;
они не являются полной резервной копией Room. Не обещать сохранение данных
при переустановке. Подробности фактической подписи и результата CI фиксируются
после проверки установочного файла.

## Следующая физическая проверка после подтверждения артефакта

Один полный автоматический опрос на неподвижном автомобиле с включённым
зажиганием и обычным подключением адаптера. После завершения сохранить
полный TXT и передать его для анализа. Не подбирать адреса вручную, не
повторять поездку отдельно ради каждого блока. Проверяются вся очередь,
реальные DTC, продолжение после недоступного ECU и восстановление OBD;
сохранение прежних чтений является проверкой регрессии.
