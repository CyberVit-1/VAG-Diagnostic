# Сводный кандидат0.3.19/code35

Объединены внутренние исправления перед очередным единым испытанием:

- Запасной список Gateway04A1 читается в том же живом канале после полного
  допустимого отказа1A9F. Новый канал остаётся для подтверждённого завершения
  сеанса самим ECU. См. GATEWAY_CHANNEL_REUSE_2026-11-14.md.
- Здоровое молчание проверки SAE-формата выбирает OEM DTC без лишнего
  переподключения. Повреждённый обмен не переиспользуется.
- Устаревший ACK не подтверждает запрос, но не уничтожает следующие
  правильные ACK и данные. Прежние ограничения и проверки полноты сохранены.
- Уточнена формулировка связи G85/MK70: базовая установка через44 не
  доказывает отсутствие отдельной памяти ошибок04.

Последний собственный физический журнал0.3.18 подтвердил16 OEM-чтений;
04/46 не ответили отдельно. Ни скорость, ни поведение нового кандидата на
автомобиле ещё не подтверждены. Список Gateway и связь функций с другим
блоком не прибавляют собственных чтений и не дают вымышленных нулевых DTC.

Версия0.3.19 ранее была только внутренним срезом. К выдаче допускается
конкретный артефакт окончательного проверенного source, а не любой ранний
APK с тем же versionName. Полные проверки и фактический артефакт фиксируются
отдельно перед выдачей. Итоговый source1b8d428 проверен:553 теста, CI43617804984 SUCCESS,
ART фактического APK248+11 PASS. [Артефакт и действие](VERIFICATION_0.3.19.md).

Следующее единое испытание после выдачи: полный автоматический опрос и TXT.
Проверяются получение списка, собственные DTC каждого отвечающего ECU,
сохранность результатов, продолжение очереди и завершение соединения.
Число успешно прочитанных ECU заранее не задаётся. Неподтверждённый ответ
остаётся видимым; неподдерживаемое данным интерфейсом чтение не имитируется.

Пакет com.vagdiagnostic.app, Room v1 и привычный способ чистой установки
сохранены. Для этой версии не требуется отдельная проверка каждого
внутреннего изменения на автомобиле.
