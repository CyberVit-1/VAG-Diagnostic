# VAG Diagnostic 0.3.6 / 22

Объединённый кандидат для следующего реального испытания. Ветка feature/initial-android-build, draft PR#1; main не изменён. Это не заявление полного охвата всех VAG или успешного автомобильного теста новой версии.

## Что объединено после физической0.3.4

- Полные составные TP2.0 ответы списка иDTC, строгие длины/SID/DID/sequence; повреждённое продолжение не заменяется корректным префиксом.
- ACK сохраняет входящие кадры, в том числе финал ResponsePending. Завершённый NRC не превращается в «нет ответа» и не переключает протокол DTC. Повреждённое согласование канала прекращает обмен.
- Полные прочитанные DTC сохраняются при последующем сбое или отмене завершения сессии. Предыдущие результаты сохраняются до опциональной идентификации/поиска.
- UDS-присутствие3E00 отделено от поддержки расширенной сессии1003. NO DATA/завершённый отказ1003 не выдаются за успешную сессию;1001 отправляется только после положительного1003.
- Закрытый каталог159байтовых ID и известные битовые форматы Gateway, выбираемые по проверенному номеруF187. Неизвестные биты и неподдержанные дочерние списки остаются неполным охватом.
- Дополнительная фиксированная legacy-процедура при отсутствии61 в полученном списке: проверенная связь/идентификация09, исключение13UDS-only префиксов, TP33/1A9B. Только полный диагностический ответ подтверждаетECU. NO DATA не создаёт строку; найденныйECU читается по подтверждённомуTP независимо от протоколаGateway. Процедура не выполняется без ранее подтверждённого09, не перебирает каталог и не подбирает адреса магнитолы.
- VIN отображается локально на главной/экране подключения после подтверждённого0902. Он не добавлен к результатам/сводным событиям; TXT скрывает целиком0902/F190, включаяHEX/ISO-TP фрагменты, и удаляет текстовые значения. Фактический VIN не используется в исходниках/тестах.
- Сохранена сворачиваемая сводка результатов: список блоков занимает основную область экрана.

## Внимание: сохранность данных

Один package com.vagdiagnostic.app: устанавливать поверх при совместимой подписи, параллельной установки нет. Room v1 не менялась, destructive migration отсутствует. Сначала сохранить и проверить нужные внешниеTXT. Если Android сообщает конфликт подписи, остановиться: удаление старой программы удалит внутренние историюRoom, журнал и настройки. ВнешнийTXT сохранится, но не восстановит всюRoom/настройки. Подпись конкретного передаваемогоAPK сравнивается с прежней0.3.4 перед выдачей; не обещать совместимость по одному package.

## Один объединённый тест

1. Установить проверенный0.3.6 с учётом сохранности данных, открыть настройки и убедиться в версии0.3.6. Автомобиль неподвижен, зажигание включено; подключить обычный адаптер и телефон привычным способом.
2. Дождаться подтверждения связи с автомобилем и запустить одно полное сканирование. Специальная пауза20–30секунд не нужна; дополнительные ручные адреса/проверки не вводить.
3. Дождаться завершения либо сообщения об ошибке. Не запускать повтор автоматически приNO DATA: сохранить этот сеанс. Проверить список блоков и раскрытые DTC; недоступность56 не считать нулём ошибок.
4. На главной проверить отображениеVIN после сканирования. Не присылать скриншот сVIN. Открыть «Настройки» → экспортTXT, убедиться, чтоVIN скрыт, и передать полныйTXT. При необходимости приложить только скриншот результатов безVIN.

Из новогоRAW проверяются реальные ответы3E00/1003, сохранение существующихDTC, применение09/61процедуры и её фактический результат, отказы/тайм-ауты и восстановление штатногоOBD. Отсутствие нового блока допустимо как результат проверки, не доказательство полного охвата. Дальше — анализ одного полного журнала, без объявления успеха заранее.
