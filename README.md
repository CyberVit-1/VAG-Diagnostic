# VAG Diagnostic

Android-приложение для автоматического обнаружения блоков VAG и чтения DTC.
Текущий кандидат: **0.3.19 / code35**, ветка feature/initial-android-build.
Диагностика только на чтение; отсутствие ответа отличается от отсутствия ошибок.

Программно проверено:553 unit-теста, успешный CI,248+11 сценариев на Android
с конкретным CI APK. На автомобиле последняя подтверждённая версия0.3.18
прочитала16 собственных OEM-памятей. Отдельные04/46 ещё не прочитаны;
полный охват всех установленных ECU и скорость0.3.19 не подтверждены.
