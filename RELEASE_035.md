**Внутренняя программно проверенная точка. Автомобильное испытание сейчас не запрашивается: цель полного обнаружения установленных ECU и чтения их DTC ещё не достигнута.**

Объединённый кандидат на базе0.3.4, ветка feature/initial-android-build, draft PR#1. main не изменяется.

## Изменения

- TP2.0:12-битная длина, явно объявленные дополнительные прикладные сообщения списка/идентификации, последовательные ACK без сброса sequence. Ограничения:16сообщений/16384байта/256итераций; конечные сроки. Обычный односообщенческий ответ не требует лишних запросов.
- Любой неполный/повреждённый обмен после отправки TP запроса прекращает дальнейшие команды. Завершённый отрицательный ответ отделён от потери ответа; предыдущие DTC сохраняются.
- 04A1: сборка нескольких сообщений, объединение повторных ID без увеличения счётчика. Исходные записи сохраняются; конфликт TP адресов блокирует опрос этого ECU.
- Идентификация: после известного отказа сервиса1A используется F187 поверх того же TP канала. Для поддержанного1A сохранён1A9B; только завершённый известный отказ допускает запасную команду. Ошибка метаданных не превращает DTC в неуспешные.
- Закрытый каталог35маршрутов вместо19. Новые16 требуют фактического ID Gateway, не добавляются как найденные сами по себе. Резервная очередь14кандидатов без списка не расширена.
- Регрессионные записи двух полных OEM обменов578/601команда, проверки порядка и возвратаOBD. Новый F187 в записи0.3.4 — явно синтетическая замена только этапа метаданных. Дополнительные сценарии: обрыв посреди очереди, сохранение результатов, повреждённое/потерянное продолжение, лишние сообщения, лимит сообщений, повторные ID, конфликт маршрутов.

Wi-Fi Network.socketFactory, отдельные SPP/BLE драйверы, постоянный applicationId com.vagdiagnostic.app, Room v1 и пользовательская история не менялись. Программа остаётся только для чтения.

## Что требуется от пользователя сейчас

Ничего не требуется. Не запрашивать повтор прежних15чтений или отдельный визит ради идентификации Gateway. Текущая задача — восстановить целиком read-only цепочку выбора подключения, получения списка, проверки присутствия и чтения DTC с запасными ветвями. Полный охват не подменять расширением таблицы, собственным экспериментальным поиском либо успешной сборкой. Следующее автомобильное испытание допустимо после целостного сопоставления механизма и программных проверок, когда без физического ответа нельзя двигаться дальше.

До установки сохранить и проверить внешниеTXT. Тот же applicationId означает установку поверх только при совпадении подписи; параллельная установка невозможна. Другая debug-подписьCI может потребовать удаления старой версии, которое удаляет внутреннюю историюRoom, журнал и настройки. TXT сохраняет внешнее доказательство, но не является полной копиейRoom. Подпись нового артефакта сравнивается при передачеAPK.
