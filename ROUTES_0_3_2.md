Вариант комфорта 17FC008B/17FE008B подтверждён статическим анализом настройки и конструктора пары адресов; совместимость с адаптером пользователя требует испытания.

## Выбор маршрута

Пять новых ID опрашиваются только после достоверного Installation List. Без него резервная очередь остаётся прежними 14 кандидатами. Общая таблица содержит 19 ID, включая отсутствующий в последнем списке стояночный тормоз 53. Наличие маршрута не означает установленность или успешное чтение.

Адрес TP из 04A1 сохраняется вместе с дополнительным статусом. Если он расходится с таблицей, блок остаётся видимым, но трафик к нему не отправляется; событие VAG_ROUTE_MISMATCH сохраняет обе величины. Неизвестные ID также не получают вымышленных маршрутов.

Для 46 после завершённого отказа TP2.0 разрешён известный 11-битный UDS, затем только при подтверждённом списке — фиксированный 29-битный вариант. Завершённый NO DATA при открытии UDS не считается ошибкой транспорта. IOException, чужой адрес/SID, незавершённый pending или неподтверждённое закрытие сессии прекращают дальнейшие попытки. Отказ не означает отсутствие DTC.

## 29-битный ELM

Фиксированный вариант 46: CAN7 (29 бит/500 кбит/с), ATCP17, ATSHFC008B, ATCRA17FE008B. Flow control задаётся явно: ATFCSH17FC008B, ATFCSD300000, ATFCSM1. ATDPN должен подтвердить 7/A7 до запроса. Автоматический FC выключен во время настройки и включается после неё. При возврате к 11-битному UDS восстанавливается ATFCSM0; сбой восстановления останавливает обмен. TP2.0 держит CFC0; штатный OBD возвращается через прежний новый сеанс/ATZ.

Общий декодер и receive-only SF проверяют полный 29-битный ID. Отложенный FF после раннего prompt в ATMA по-прежнему не поддержан. Обычные многофреймовые ответы обрабатываются с FC адаптера. Справочник команд — [ELM327 DSL](https://www.elmelectronics.com/wp-content/uploads/2020/05/ELM327DSL.pdf), CP/SH, CRA и FCSH/FCSD/FCSM.

## Сворачиваемая сводка

Пользователь выбрал сворачиваемую сводку. Числа, кнопка запуска/остановки и отметка неполного опроса видны в компактном блоке; подробные счётчики, режимы и пояснения раскрываются по нажатию. После завершения сканирования сводка сворачивается. Сводка и карточки находятся в одной LazyColumn с постоянными ключами: раскрытые подробности не сжимают список в фиксированный остаток экрана. Переключение сводки не сбрасывает раскрытие ECU-карточек.

UI проверяется Android-компиляцией; фактический вид и жесты на телефоне пока не проверены. Синтетические сценарии не являются физическим тестом. Package ID и Room schema неизменны; режим остаётся только для чтения.
